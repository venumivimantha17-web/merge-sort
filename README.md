# Python Merge Sort

A Python implementation of the **Merge Sort** algorithm using **recursion** and the **divide-and-conquer** approach.

## 📌 Overview

Merge Sort divides an unsorted list into smaller sublists, recursively sorts those sublists, and then merges them to produce a sorted list.

## 🚀 Features

* Recursive Merge Sort implementation
* Divide-and-conquer approach
* Sorts numbers in ascending order
* Demonstrates Python recursion and list slicing
* Includes a sample input and output

## 🛠️ Technologies

* Python 3

## ▶️ How to Run

Clone the repository and run:

```bash
python merge_sort.py
```

## 💻 Example

### Input

```text
[4, 10, 6, 14, 2, 1, 8, 5]
```

### Output

```text
Unsorted array:
[4, 10, 6, 14, 2, 1, 8, 5]

Sorted array:
[1, 2, 4, 5, 6, 8, 10, 14]
```

## 🧠 Algorithm

1. Find the middle point of the list.
2. Divide the list into left and right halves.
3. Recursively sort both halves.
4. Compare elements from both sorted halves.
5. Merge the elements into the original list.
6. Continue until the complete list is sorted.

## ⏱️ Complexity

* **Time Complexity:** O(n log n)
* **Space Complexity:** O(n)
